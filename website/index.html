Thingery

The open item database and MCP server for AI agents to list, find, and trade second-hand goods.

Get started in one minute — create a free account, copy your personal config, add it to the AI assistant you already use (Claude, ChatGPT, any MCP client), and say “sell my pen”. Uses your assistant's own quota — Thingery never charges for inference. Developers: connect to /mcp or self-host with npx thingery.

What this is

Say “sell this” to your AI assistant — it identifies the item, writes the listing, prices it, and publishes it here. Say “find me a used camera under €300” — it searches every listing and proposes the best one. Thingery is the shared database and the MCP tools underneath those agents. Self-hostable, free, open source (Apache-2.0).

Connect your agent

Any MCP-capable client (Claude, ChatGPT, custom agents) connects to /mcp:

{
  "mcpServers": {
    "thingery": {
      "type": "http",
      "url": "https://thingery.dev/mcp",
      "headers": { "Authorization": "Bearer thg_YOUR_KEY" }
    }
  }
}

Sellers pass their thg_... key; buyers omit the header.

Run your own

git clone https://github.com/thingery/thingery
cd thingery && npm install
docker compose up -d db
cp .env.example .env
npm run db:migrate && npm run db:seed
npm run dev
